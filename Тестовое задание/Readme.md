Предлагаю такое решение:

Сначала любая быстрая фильтрация по правилам(зависит от контекста), для оставшегося:

1. **Предобработка**

	Удаление пунктуации, нижний регистр и пр.

2. **Создание признаков**

	Бренд, характеристики товаров(на основе регулярных выражений)

3. **Текст в векторы**

	* усреднённые эмбеддинги

	* выбираем по пороговое значение

	* фильтрация по косинусной близости

	word2vec или BERT(учитывает семантику)

4. **Кластеризация**

    DBSCAN по причине неизвестного количества классов
